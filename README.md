# 🎵 Audio Player App (Jetpack Compose + ExoPlayer)

An Android Audio Player App built using **Kotlin**, **Jetpack Compose**, and **ExoPlayer**.  
This is a personal project developed after completing exams and while working full-time — progress may have been slow, but the learning never stopped! 💪

---

## 📱 Features

- 🎶 Play all audio files from local storage
- 👆 Swipe to play the next or previous song
- 🎚️ Seek bar to navigate within a track
- 🔁 Repeat | ⏮️ Previous | ⏭️ Next controls
- 📦 Mini Player UI for quick access

---

## 🧰 Tech Stack

- **Language**: Kotlin  
- **UI Toolkit**: Jetpack Compose  
- **Media Playback**: [ExoPlayer](https://github.com/google/ExoPlayer)  
- **Architecture**: MVVM  

---
